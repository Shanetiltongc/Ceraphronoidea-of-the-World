# Ceraphronoidea of the World

Public TaxonPages site for the superfamily Ceraphronoidea (Hymenoptera), served from TaxonWorks. Nomenclature is based on Johnson & Musetti (2004), *Catalog of Systematic Literature of the Superfamily Ceraphronoidea (Hymenoptera)*.

Live site: https://shanetiltongc.github.io/Ceraphronoidea-of-the-World/

## Local development

```powershell
npm install
npm run dev
```

The site runs at http://localhost:5173/. Local `base_url` stays `/`. GitHub Actions rewrites it to `/Ceraphronoidea-of-the-World/` for Pages.

## GitHub Pages

Pushes to `main` build and deploy with GitHub Actions. Enable **Settings → Pages → Source: GitHub Actions** if the first deploy asks for it.
